# Contributing to TxtPDF

Thanks for taking the time to improve TxtPDF! This project is intentionally small and dependency-free, so contributions should keep it that way.

## Getting started

1. Fork the repository and clone your fork.
2. Open `index.html` in a browser. There is no build step.
3. Create a branch: `git checkout -b feature/short-description`.

## Guidelines

- Keep changes small and focused: one idea per commit.
- Use plain HTML, CSS and JavaScript. Please do not add frameworks.
- Follow the settings in `.editorconfig`.
- Test in at least one Chromium-based browser and one other browser if you can.
- Check that the printed output (Ctrl/Cmd + P) still looks right.

## Commit messages

Write short, imperative messages, for example:

- `Add marks limit to question input`
- `Fix preview not updating after delete`

## Reporting bugs and ideas

Open an issue and describe what you expected and what happened. Screenshots of the preview or the printed PDF are very helpful.
