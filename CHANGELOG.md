# Changelog

All notable changes to this project are documented here.

## [1.1.0]

### Added
- Autosave of the current draft in the browser.
- Export and import of tests as JSON, with validation.
- Duplicate question and Clear All buttons.
- Live question counter.
- Choose the number of answer lines per question.
- `Ctrl/Cmd + Enter` shortcut to add a question.
- Marks limited to 1-100.
- Dark mode for the editor (the preview stays white).
- Accessibility labels and `prefers-reduced-motion` support.
- SVG favicon, web app manifest and social meta tags.
- GitHub Actions workflow for syntax and HTML checks.
- Documentation: contributing guide, code of conduct, security policy, usage guide, FAQ, architecture notes.
- Issue and pull request templates.

### Changed
- Larger tap targets on small screens.
- Clearer answer line spacing when printing.
