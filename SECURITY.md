# Security Policy

TxtPDF runs entirely in your browser. It has no server, no accounts, and sends no data anywhere. Drafts are stored only in your own browser's `localStorage`.

## Reporting a vulnerability

If you find a security problem (for example an HTML injection in the preview), please open a GitHub issue with the label `security`, or contact the repository owner privately through GitHub. Please include steps to reproduce.

## Supported versions

Only the latest version on the `main` branch is supported.
