# Usage Guide

## Create a test paper

1. Open `index.html` in a modern browser (Chrome, Edge, Firefox, Safari).
2. Enter the **Test Title**, **Student Name** and **Subject**.
3. Click **+ Add Question**, type the question, and set the marks.
4. Repeat for every question. The preview at the bottom updates as you type.
5. Click **Generate PDF**.
6. In the print dialog choose **Save as PDF** as the destination.

## Tips

- The test title is used as the default PDF file name.
- Total marks are calculated automatically.
- Deleting a question that already has text asks for confirmation.
- Use A4 paper and the default margins for the best result.
