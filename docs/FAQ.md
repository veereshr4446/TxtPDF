# FAQ

**Does my data leave my computer?**
No. Everything happens in your browser.

**Why does the PDF button open a print dialog?**
The app uses the browser's built-in "Save as PDF" feature, so no extra libraries are needed.

**Can I change the paper size?**
The page is set to A4 in `style.css` (`@page` rule). Change it to `letter` if you need US Letter.

**Does it work offline?**
Yes. Save the folder and open `index.html`; there is no network access required.

**The preview shows but the PDF is blank.**
Make sure "Background graphics" is not required, and that you added at least one question.
